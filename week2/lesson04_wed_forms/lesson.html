Description

Forms let a website ask the user questions, like a name or an email address. Today we learn the basic pieces of a form — later, JavaScript will make them actually do something.

Key Concepts

  • <form> wraps all the pieces of a form
  • <input type="text"> for typed answers
  • <input type="number">, type="email" for special answers
  • <label> describes what an input is for
  • <input type="checkbox"> for yes/no choices
  • <button> to submit the form

Code Samples

What it does: label describes the input; the for and id must match so they're connected.

<label for="name">Your Name:</label>
<input type="text" id="name" name="name">

What it does: type changes what kind of answer the input expects.

<input type="number" placeholder="Your age">
<input type="email" placeholder="you@example.com">

What it does: A checkbox can be checked or unchecked — great for yes/no questions.

<input type="checkbox" id="agree">
<label for="agree">I agree</label>

What it does: A button submits the form when clicked.

<button>Submit</button>

Example

A simple sign-up form:

<h1>Sign Up</h1>
<form>
  <label for="name">Name:</label>
  <input type="text" id="name"><br>
  <label for="email">Email:</label>
  <input type="email" id="email"><br>
  <input type="checkbox" id="fun">
  <label for="fun">I like having fun</label><br>
  <button>Submit</button>
</form>

Exercises

  • Build a small form asking for a name and favorite color (text inputs).
  • Add a submit button to your form.
  • Add one checkbox for ‘I like pizza’.
  • Put your form inside a <main> tag with an <h1> title above it.
