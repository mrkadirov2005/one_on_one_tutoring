Intro to CSS — Making Pages PrettyWeek 2 · Saturday

Description

CSS (Cascading Style Sheets) controls how HTML looks — colors, fonts, spacing. Today we learn the 3 ways to add CSS and how to ‘select’ which HTML elements to style.

Key Concepts

  • CSS is the styling language for HTML
  • Inline CSS: a style="..." attribute on one tag
  • Internal CSS: a <style> block inside <head>
  • External CSS: a separate .css file linked with <link>
  • Selectors: element (p), class (.name), id (#name)
  • Common properties: color, background-color, font-family, font-size

Code Samples

What it does: Inline CSS styles just one single tag, written right on it.

<p style="color: blue;">Blue text</p>

What it does: Internal CSS goes inside a <style> tag in the <head> and can style the whole page.

<style>
  p {
    color: green;
  }
</style>

What it does: External CSS lives in its own .css file and is linked into the HTML page.

<link rel="stylesheet" href="style.css">

/* inside style.css */
p { color: purple; }

What it does: A class selector (.name) can be reused on many tags; an id selector (#name) is for one unique tag.

p { color: black; }        /* every paragraph */
.highlight { color: red; }  /* class="highlight" */
#title { font-size: 30px; } /* id="title" */

Example

A page styled with an internal <style> block:

<head>
  <style>
    #title { color: darkgreen; font-size: 32px; }
    .highlight { color: orange; font-family: Arial; }
  </style>
</head>
<body>
  <h1 id="title">Welcome!</h1>
  <p class="highlight">This paragraph stands out.</p>
</body>
