Formatting Text, Lists, Links & ImagesWeek 1 · Saturday

Description

Now that you can build a page, let's make it richer: bold and italic text, bullet and numbered lists, clickable links, and pictures.

Key Concepts

  • <strong> for bold, <em> for italic
  • <br> for a line break, <hr> for a divider line
  • Unordered (bullet) list: <ul><li>
  • Ordered (numbered) list: <ol><li>
  • Links: <a href="...">text</a>
  • Images: <img src="..." alt="...">

Code Samples

What it does: strong makes text bold and important; em makes text emphasized (italic).

<p>This is <strong>important</strong> and this is <em>emphasized</em>.</p>

What it does: br breaks to a new line; hr draws a horizontal divider line.

<p>Line one<br>Line two</p>
<hr>

What it does: ul makes a bullet list, ol makes a numbered list — each item goes in <li>.

<ul>
  <li>Apples</li>
  <li>Bananas</li>
</ul>
<ol>
  <li>Wake up</li>
  <li>Brush teeth</li>
</ol>

What it does: href is the address the link goes to; the text between the tags is what people click.

<a href="https://www.google.com">Go to Google</a>

What it does: src is the image file; alt describes the image (for people who can't see it).

<img src="cat.jpg" alt="A cute orange cat">

Example

A small ‘My Favorite Things’ page:

<h1>My Favorite Things</h1>
<p>I <strong>really</strong> love pizza and I <em>kind of</em> like broccoli.</p>
<ul>
  <li>Pizza</li>
  <li>Football</li>
  <li>Video games</li>
</ul>
<a href="https://www.nasa.gov">Visit NASA</a>
<img src="space.jpg" alt="A photo of outer space">
