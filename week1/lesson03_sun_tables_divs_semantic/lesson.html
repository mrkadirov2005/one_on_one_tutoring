Tables, Divs, Spans & Semantic TagsWeek 1 · Sunday

Description

Websites need ways to group content and show data in rows and columns. Today: tables for data, div/span as generic containers, and semantic tags that describe what a section of the page is for.

Key Concepts

  • <table>, <tr> (row), <td> (cell), <th> (header cell)
  • <div> = a block container (starts on a new line)
  • <span> = an inline container (stays in the text flow)
  • Semantic tags: <header>, <nav>, <main>, <footer>
  • Semantic tags make pages easier to read and understand

Code Samples

What it does: A table is built from rows (tr) made of cells (td); th is a bold header cell.

<table>
  <tr>
    <th>Name</th>
    <th>Age</th>
  </tr>
  <tr>
    <td>Ali</td>
    <td>11</td>
  </tr>
</table>

What it does: div groups a block of content; span highlights a small piece of text inside a sentence.

<div>
  This is a block. It starts on a new line.
</div>
<p>This has a <span>highlighted word</span> inside it.</p>

What it does: Semantic tags name what each part of the page is for, instead of using plain divs everywhere.

<header>My Website</header>
<nav>Home | About | Contact</nav>
<main>Main content goes here.</main>
<footer>Made by me, 2026</footer>

Example

A simple class schedule table inside a semantic page layout:

<header><h1>My Website</h1></header>
<nav>Home | About</nav>
<main>
  <table>
    <tr><th>Day</th><th>Subject</th></tr>
    <tr><td>Monday</td><td>Math</td></tr>
    <tr><td>Tuesday</td><td>Art</td></tr>
  </table>
</main>
<footer>Thanks for visiting!</footer>

Exercises

  • Use a <div> to group the list you made in Lesson 2.
  • Use a <span> to highlight one word inside a paragraph.
