Styling Text & BackgroundsWeek 3 · Wednesday

Homework check Today we review the homework assigned in Intro to CSS — Making Pages Pretty (Saturday, Week 2).

Description

Let's make our pages look more finished: better fonts, text alignment, and background colors.

Key Concepts

  • font-family sets the typeface (with backup fonts)
  • font-size and font-weight control text size and boldness
  • text-align: left, center, or right
  • background-color colors the whole box behind the content
  • background-image can add a picture behind content (used carefully)

Code Samples

What it does: font-family can list several fonts — the browser uses the first one it has.

body {
  font-family: Arial, sans-serif;
  font-size: 18px;
}

What it does: font-weight controls boldness; text-align controls horizontal position.

h1 {
  font-weight: bold;
  text-align: center;
}

What it does: background-color fills the box behind the text with a color.

body {
  background-color: #f0f8ff;
}

What it does: background-image puts a picture behind the content of a box.

div {
  background-image: url("bg.jpg");
}

Example

A page with a centered heading and a light background:

<style>
  body {
    font-family: Arial, sans-serif;
    background-color: #f0f8ff;
  }
  h1 {
    text-align: center;
    font-weight: bold;
  }
</style>

Exercises

  • Change your whole page's font-family and font-size on the body.
  • Center your <h1> using text-align.
  • Give your page's <body> a light background-color.
  • Review: your card <div> (Lesson 6) should still have padding/border/margin.
  • Review: your form and table (Lessons 3–4) should still be visible on the page.
