DOM Basics & Final Project — Bringing It All TogetherWeek 4 · Sunday

Description

The DOM (Document Object Model) is how JavaScript ‘sees’ and changes your HTML. Today: selecting elements, changing their text/style, reacting to clicks, and building one final project using HTML + CSS + JS together.

Key Concepts

  • The DOM is JavaScript's live map of the HTML page
  • document.getElementById() / document.querySelector() select elements
  • .textContent changes an element's text
  • .style changes an element's CSS from JavaScript
  • addEventListener("click", ...) reacts to clicks

Code Samples

What it does: getElementById finds one element by its id; querySelector finds one by a CSS-style selector.

const title = document.getElementById("title");
const box = document.querySelector(".card");

What it does: Once selected, we can change what an element shows and how it looks.

title.textContent = "New Title!";
title.style.color = "red";

What it does: addEventListener runs a function every time that event (like a click) happens.

const button = document.querySelector("button");
button.addEventListener("click", function() {
  console.log("Button was clicked!");
});

What it does: We can combine selecting and events to make a button change the page.

button.addEventListener("click", function() {
  title.style.color = "blue";
});

Example

A button that changes the profile card's heading when clicked:

const heading = document.querySelector("h2");
const button = document.querySelector("button");

button.addEventListener("click", function() {
  heading.textContent = "Thanks for clicking!";
  heading.style.color = "blue";
});

Exercises

  • Use document.querySelector to select the button and your <h2> name heading.
  • Add a click event: when clicked, change the heading's text and color.
  • Bonus: add a second button that changes the background-color of the whole page.
  • Final Project: present your complete profile card page (HTML + CSS + JS) — structure, styling, and the interactive button.
