Operators, If/Else & Simple FunctionsWeek 4 · Saturday

Description

Now let's make JavaScript make decisions and reuse code. We'll learn math and comparison operators, if/else statements, and how to write our own simple functions.

Key Concepts

  • Math operators: +, -, *, /
  • Comparison operators: ===, >, <
  • if / else statements make decisions
  • Functions let us reuse a block of code

Code Samples

What it does: Math operators work just like in math class.

let total = 5 + 3;
let result = 10 - 4;

What it does: Comparison operators check something and give back true or false.

console.log(5 > 3);    // true
console.log(5 === 5);  // true

What it does: if runs code only when the condition is true; else runs when it's false.

let age = 11;
if (age >= 10) {
  console.log("You are a preteen or older!");
} else {
  console.log("You are younger than 10.");
}

What it does: A function is a named, reusable block of code. We call it by its name.

function greet(name) {
  console.log("Hello, " + name + "!");
}
greet("Ali");

Example

A function that checks if a number is even or odd:

function checkNumber(n) {
  if (n % 2 === 0) {
    console.log(n + " is even");
  } else {
    console.log(n + " is odd");
  }
}
checkNumber(4);
checkNumber(7);
