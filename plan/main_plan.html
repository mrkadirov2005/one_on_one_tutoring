One-Month HTML/CSS/JS Course
For two beginner students (ages ~10–12)

Context

The user is privately tutoring two beginner students, 3 sessions a week (Wed, Sat, Sun). Homework is assigned Saturday and reviewed the following Wednesday — Sunday has no homework check since there's no gap before it. In one month (12 lessons) the course must cover HTML, CSS, and JS basics. Every lesson has two deliverables: one lesson HTML page and one PPT slide deck, both built from a fixed, simplified structure, kept small, with no overcomplication.

Confirmed decisions:

  • PPTs are real .pptx files, generated with python-pptx (needs pip install python-pptx).
  • Layout: week1/…week4/ folders, each with one subfolder per lesson containing lesson.html + slides.pptx.

Curriculum (introduction + 12 lessons)

Introduction — Setup & Course Overview (first class)

  • Setup: Chrome, VS Code, the Live Server extension, a my-website folder, Chrome DevTools, file extensions (Windows), save/undo shortcuts.
  • Course summary: what each week teaches, plus the homework rhythm (given Saturday, checked Wednesday).
  • End-of-month outcomes: build a full page from scratch, style it with CSS and flexbox, write simple JS, and make an interactive profile card.

Week 1 — HTML Foundations

  1. Wed — What is HTML? Page structure (<!DOCTYPE>, html, head, body), headings, paragraphs, comments.
  2. Sat — Text formatting (bold/italic/line breaks), lists (ul/ol/li), links (a), images (img). Homework assigned.
  3. Sun — Tables (table/tr/td/th), div/span, intro to semantic tags (header, nav, main, footer).

Week 2 — HTML wrap-up + CSS intro

  1. Wed — Check Sat HW. Forms & inputs (form, input types, label, button).
  2. Sat — Intro to CSS: what CSS is, 3 ways to apply it (inline/internal/external), selectors (element/class/id), colors & fonts. Homework assigned.
  3. Sun — CSS Box Model: margin, border, padding, width/height.

Week 3 — CSS deep dive

  1. Wed — Check Sat HW. Text styling & backgrounds (font-family, font-size, text-align, background-color, background-image).
  2. Sat — Flexbox basics (display:flex, justify-content, align-items, flex-direction). Homework assigned.
  3. Sun — Mini project: build a simple "profile card" page combining everything from Weeks 1–3.

Week 4 — JavaScript basics

  1. Wed — Check Sat HW. Intro to JS: variables (let/const), data types, console.log, linking a .js file to HTML.
  2. Sat — Operators, if/else, simple functions. Homework assigned.
  3. Sun — DOM basics: getElementById/querySelector, changing text/style, click events. Final mini project combining HTML+CSS+JS.

Every lesson's exercises section is cumulative — it reuses concepts from all prior lessons plus the new material. No images are used anywhere (not needed at this basic level); everything stays plain HTML/CSS/JS snippets.

Lesson structure (identical for every lesson)

Each lesson.html follows exactly this order:

  1. Topic (title)
  2. Description (2–4 simple sentences, no jargon)
  3. Key Concepts (short bullet list)
  4. Code Samples/Snippets (small code blocks, each with a one-line plain-English definition above it)
  5. Examples (a slightly bigger worked example showing the concepts together)
  6. Exercises (3–5 short, easy tasks — cumulative with prior lessons)

Each slides.pptx mirrors the same structure in ~6–8 slides: Title → Description → Key Concepts → 1–2 Code slides → Example → Exercises. Plain, large, readable text (kid-friendly), one consistent simple color theme, no images.
